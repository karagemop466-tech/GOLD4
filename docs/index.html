The Key Rule

A 14K or 18K stamp by itself does not prove the ring is that purity. Safest approach: reputable seller + proper markings (karat stamp + maker's mark) + reasonable price vs. gold melt value + independent testing (ask for XRF) after delivery. If a seller won't let you independently verify or return it — don't buy it.

How to use this site (no manual data entry needed from the data file)

  1. Pick a candidate on Ring Candidates and open its official link.
  2. Run the Checklist against the listing; note karat, "solid gold" wording, hallmark, gram weight, price + date.
  3. Put weight/karat/spot into the Calculator — if asking price is near/below melt, or weight is refused, walk away.
  4. After delivery, before wearing/resizing: independent jeweler + XRF test.
