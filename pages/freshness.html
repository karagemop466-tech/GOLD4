⚠ NO HALLUCINATIONS — read before using any number

No hallucinations. This project manufactures no values. A price, weight, karat, deadline or contact detail is only shown if it was read from the official page linked in the same row. The consumer rules being applied come from the FTC's guidance on buying gold jewelry and 15 U.S.C. § 295.

  • Blank means blank. If a retailer did not publish a gram weight, the weight cell stays empty — it is never estimated from photos, blogs or "typical" rings.
  • Every row carries its source. Open the source link and confirm the number yourself; prices change without notice.
  • Derived ≠ claimed. Gold content and gold value are arithmetic on published values at the captured spot price, and are labelled as derived.
  • Anything uncertain is published on Flagged for Review with the reason and the source, instead of being quietly filled in.
  • Re-run the check after every review. python3 scripts/audit.py re-derives every number and fails the build on an unsourced value. When you review this dataset, ask of each row: where is the official source, and what date was it read? If a row cannot answer that, treat it as unverified and flag it — including anything added by a previous pass.

What each state means — and what it does not mean

Reading the check honestly

  • Page served and read — a 200 response with product text. The price is compared with the page's own schema.org offer price.
  • 404 — the URL stored beside the value no longer resolves. The value stays as captured (with its original date) and is flagged SOURCE_URL_DEAD; it is not re-confirmed and not silently deleted.
  • 403 — the retailer's bot protection refused the runner. That is a statement about the runner, not about the price. No claim is made.
  • JavaScript-only — the server sends a shell; the price is rendered in the browser. Again, no claim is made.
  • Differs — the page's structured offer price is a different number (usually a different variant/configuration selected on that page). Both numbers are published; the stored value is not overwritten without a human reading the page.

How to reproduce this page

python3 scripts/live_source_check.py performs read-only GETs against the allow-listed hostnames in data/sources.json and writes reports/live_source_check_latest.json. python3 scripts/build_source_health.py reconciles that artifact with the dataset into data/source_health.json, and python3 scripts/build_site.py renders this page. The check is re-run by CI on every pull request that touches the data.

Rules baked into the reconciliation: nothing overwrites a stored value; a page that cannot be fetched says nothing about its price; no currency conversion, no averaging, no interpolation.

No-hallucination policy: every price, weight, policy and link on this site was read from the official page named beside it on 22 October 2026. Where a value could not be read, the cell is blank and the row is on the Flagged for Review page.

Gold benchmark: $4,024.45/oz as of 22 October, 2026 (World Gold Council) = $129.3891/g. Derived values are arithmetic on retailer-published inputs, not appraisals.
