⚠ NO HALLUCINATIONS — read before using any number

No hallucinations. This project manufactures no values. A price, weight, karat, deadline or contact detail is only shown if it was read from the official page linked in the same row. The consumer rules being applied come from the FTC's guidance on buying gold jewelry and 15 U.S.C. § 295.

  • Blank means blank. If a retailer did not publish a gram weight, the weight cell stays empty — it is never estimated from photos, blogs or "typical" rings.
  • Every row carries its source. Open the source link and confirm the number yourself; prices change without notice.
  • Derived ≠ claimed. Gold content and gold value are arithmetic on published values at the captured spot price, and are labelled as derived.
  • Anything uncertain is published on Flagged for Review with the reason and the source, instead of being quietly filled in.
  • Re-run the check after every review. python3 scripts/audit.py re-derives every number and fails the build on an unsourced value. When you review this dataset, ask of each row: where is the official source, and what date was it read? If a row cannot answer that, treat it as unverified and flag it — including anything added by a previous pass.

Reputation is deliberately empty

No independent review or complaint data was collected for this pass, so no reputation verdict is published. A clean policy page is not evidence of a clean track record — search each seller's name with "complaint" and check your local consumer-protection body before buying.

How the return clauses bite

The resize trap

You are told to inspect the ring before resizing it. Blue Nile and VRAI both state that resized rings are not returnable, so the inspection has to happen before any sizing work — and if the ring arrives the wrong size, ask for a remake or a resize by the seller rather than a local jeweller, or you may lose the return right.

The engraving trap

Mejuri states engraved products are not eligible for return "at any time"; Allurez and Blue Nile exclude engraved items too; VRAI excludes engraving fees and engraved items. Free engraving is not free if it costs you the return.

The custom trap

Allurez makes custom-made orders non-refundable and non-cancellable. Anjolee, by contrast, publishes that all customised orders can be returned for a full refund within 30 days. If you are commissioning, that difference is worth more than the price difference.

The refund haircut

VRAI charges a $300 recycling fee on an engagement-ring refund but waives it for store credit. Blue Nile allows only two complimentary returns per year and charges $150 for a missing grading report.
