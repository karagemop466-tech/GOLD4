Methodology & Verification Log

Anti-hallucination policy

  • A value is recorded only if it was read from an official source (retailer product/category page, official price API) at a recorded UTC time, with the URL kept on the row.
  • If a value cannot be confirmed, the cell stays blank and the row is flagged UNVERIFIED and published on Flagged for Review. Nothing is inferred, estimated, or "typical-filled".
  • Automated checks run after every data change: python3 scripts/verify_data.py (schema, official-domain allow-list, karat/name consistency, fabricated-value guard on weight & hallmark, price sanity, timestamp sanity, duplicates, spot-price recomputation). Latest result: PASS_WITH_WARNINGS, errors: 0.
  • Site build regenerates every table from data/rings.json — no hand-typed numbers in HTML.
  • Local link integrity checked with scripts/check_links.py before publish.
