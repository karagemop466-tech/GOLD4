⚠ NO HALLUCINATIONS — read before using any number

No hallucinations. This project manufactures no values. A price, weight, karat, deadline or contact detail is only shown if it was read from the official page linked in the same row. The consumer rules being applied come from the FTC's guidance on buying gold jewelry and 15 U.S.C. § 295.

  • Blank means blank. If a retailer did not publish a gram weight, the weight cell stays empty — it is never estimated from photos, blogs or "typical" rings.
  • Every row carries its source. Open the source link and confirm the number yourself; prices change without notice.
  • Derived ≠ claimed. Gold content and gold value are arithmetic on published values at the captured spot price, and are labelled as derived.
  • Anything uncertain is published on Flagged for Review with the reason and the source, instead of being quietly filled in.
  • Re-run the check after every review. python3 scripts/audit.py re-derives every number and fails the build on an unsourced value. The standing recommendation, repeated after every review

Look for hallucinations again next time. For every row ask four questions in order:

  1. What is the official source link for this number? If there is no link, there is no number.
  2. What date was it read, and by what read path? "Captured last week" is not a date.
  3. Does the page still print that exact figure? If it prints something else, publish both — never overwrite.
  4. Was anything inferred? Currency conversions, "typical" weights, ranges collapsed to one number and prose that rounds a value are all inference. Inference must be labelled as derived or left blank.

Integration clarification: a 14K or 18K stamp is a claim, not proof. Seek an independent professional's appropriate complementary tests and a metal-only gram-weight check, within written testing/return permissions. A single surface XRF reading can miss thick plating or electroformed construction; see GIA's documented case. Nothing on this site substitutes for that assessment.
