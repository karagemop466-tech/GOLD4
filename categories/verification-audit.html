How Anti-Hallucination Security Checks Run After Every Review Pass

Per our front-page No Hallucinations commitment, every review pass runs python3 scripts/audit_hallucinations.py (alongside scripts/check_site.py, scripts/verify.py, and scripts/audit.py during final integration). These automated gates:

  • Recompute every troy-ounce-to-gram rate (÷ 31.1034768), diamond carat deduction (× 0.200 g), pure-gold gram weight (× karat / 24), and melt value from scratch;
  • Fail immediately on phantom math (any row where metal_weight_g is null yet pure gold or melt value is populated);
  • Block unapproved secondary blogs, forums, and peer-to-peer marketplaces (eBay, Amazon, Etsy, Reddit, Wikipedia, etc.);
  • Verify every rendered <tr data-row-id="..."> carries a direct https:// official source link and zero broken local links.
